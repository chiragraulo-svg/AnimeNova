Security & deployment

Admin authentication

Supabase Auth is used for sign-in. Admin access is granted only to accounts whose database profile has the admin role.

Shared database

Anime, episodes, ads and settings load from your Supabase project when connected.

Media storage

Poster uploads use the anime-media Supabase Storage bucket. Public reads and admin-only writes are enforced by storage policies.

Content source policy

The player supports authorized video URLs and official provider links only; it does not scrape or unlock third-party streams.

The frontend uses only the publishable key. Row Level Security and the admin role protect database writes. Never place a service-role key in browser code.

Backup / restore

Export catalogue, episodes, user demo data, ads and settings as JSON. Keep backups private.
